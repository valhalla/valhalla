# Configuration schema

Valhalla publishes a JSON Schema for the configuration generated by
`valhalla_build_config`. The schema is available in the
repository at [`schema/config_schema.json`](https://github.com/valhalla/valhalla/blob/master/schema/config_schema.json)
and is installed with Valhalla under the data directory.

The schema provides editor completion, inline descriptions, and validation for configuration
files. For example, in Visual Studio Code, add a `$schema` property to a configuration file:

```json
{
  "$schema": "https://valhalla.github.io/valhalla/config_schema.json",
  "mjolnir": {
    "tile_dir": "/data/valhalla"
  }
}
```

The schema is generated from the same defaults and help text used by
`valhalla_build_config`. To print the current schema
without using a checked-in copy:

```bash
valhalla_build_config --schema
```

Use `--output` to write it to a file:

```bash
valhalla_build_config --schema --output config_schema.json
```

The schema describes the available keys and value types. Optional configuration keys are not
listed as required. Unknown keys are rejected by schema validators so misspelled options are
reported, while Valhalla's existing runtime configuration parsing behavior remains unchanged.
